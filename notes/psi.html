PSI 분석 파이프라인

2026.02.11

1. 프로젝트 개요

Visium HD 공간 전사체(Spatial Transcriptomics) 데이터에서 대체 스플라이싱(Alternative Splicing) 패턴을 분석하는 프로젝트이다.

핵심 지표는 PSI (Percent Spliced In) 으로, 하나의 유전자에서 여러 transcript(isoform) 중 특정 isoform이 차지하는 비율을 의미한다.

PSI = (특정 transcript의 count) / (같은 유전자의 모든 transcript count 합)

예시: Plp1 유전자에서 barcode X에 transcript A가 3개, transcript B가 1개 검출되었다면

  • PSI(A) = 3/4 = 0.75
  • PSI(B) = 1/4 = 0.25

2. 데이터 구조

2.1 Visium HD 해상도 체계

Visium HD는 여러 해상도의 barcode를 제공한다:

2µm bin:  가장 작은 단위 (개별 spot)
8µm bin:  4×4 = 16개의 2µm bin을 하나로 묶은 것
16µm bin: 2×2 = 4개의 8µm bin을 하나로 묶은 것

바코드 형식:

2µm:  s_002um_{row:05d}_{col:05d}-1    예) s_002um_00396_00857-1
8µm:  s_008um_{row:05d}_{col:05d}-1    예) s_008um_00099_00214-1

2.2 입력 데이터

데이터파일설명
IsoQuant 출력OUT.transcript_grouped_tag_CB_counts.linear.tsvtranscript별 barcode별 read count (2µm 해상도, 전체 뇌)
GTF 어노테이션gencode.vM23.annotation.gtftranscript → gene 매핑 정보
AnnDataadata_cortex_8um.h5ad8µm 해상도의 cortex 영역 subset (17,880 spots × 32,285 genes)
💡 핵심 포인트:
  • IsoQuant 출력: 전체 뇌(whole brain)의 2µm 해상도 데이터
  • AnnData: cortex 영역만 잘라낸(subset) 8µm 해상도 데이터
  • 즉, 해상도도 다르고 공간 범위도 다름

3. 분석 단계별 상세 설명

Step 1: PSI 계산 (calculate_psi.py)

목적: IsoQuant의 raw count → barcode별 유전자별 PSI 계산

입력:  IsoQuant transcript count (16µm, 전체 뇌)
출력:  psi_per_barcode.tsv.gz (16µm, 전체 뇌)
처리 과정
  1. GTF 파싱: transcript_id → (gene_id, gene_name) 매핑 테이블 구축

    예: ENSMUST00000033800.12 → (ENSMUSG00000031425.15, Plp1)

  2. Count 데이터 로드: IsoQuant 출력을 chunk 단위로 읽음

    컬럼: transcript_id, barcode, count / NA barcode 제거, GTF에 없는 transcript 제거

  3. Gene total 계산: 각 (gene, barcode) 조합에서 모든 transcript의 count 합산
  4. PSI 계산:
PSI(gene G, transcript T, barcode B) = count(G, T, B) / gene_total(G, B)
  1. 필터링: barcode당 유전자별 2개 이상의 transcript가 검출된 경우만 유지
⚠️ transcript가 1개뿐이면 PSI는 항상 1.0으로, 스플라이싱 다양성 정보가 없음.

출력 파일 구조:

gene_id                  gene_name  transcript_id            barcode                count  gene_total  psi
ENSMUSG00000031425.15    Plp1       ENSMUST00000033800.12    s_016um_00024_01758-1  1.0    4.0         0.2500
ENSMUSG00000031425.15    Plp1       ENSMUST00000113085.1     s_016um_00024_01758-1  3.0    4.0         0.7500

Step 2: 2µm → 16µm 매핑 및 AnnData 통합 (integrate_psi_to_16um.py)

목적: 2µm PSI 데이터를 8µm AnnData에 통합

입력:  psi_per_barcode.tsv.gz (2µm, 전체 뇌) + adata_cortex_8um.h5ad (8µm, cortex)
출력:  adata_cortex_8um_with_psi.h5ad (8µm, cortex, PSI 포함)

Part A: 2µm → 16µm 바코드 매핑

Part A-3: 16µm 해상도에서 PSI 재계산

같은 16µm bin에 속하는 여러 2µm bin의 count를 합산한 뒤 PSI를 다시 계산한다.

예시: 16µm bin B 안에 2µm bin b1, b2, b3이 있고,
      유전자 G의 transcript T1, T2에 대해:

      2µm level:
        (G, T1, b1): count=2    (G, T2, b1): count=1
        (G, T1, b2): count=0    (G, T2, b2): count=3
        (G, T1, b3): count=1    (G, T2, b3): count=0

      16µm 합산:
        (G, T1, B): count = 2+0+1 = 3
        (G, T2, B): count = 1+3+0 = 4
        gene_total = 3+4 = 7

      16µm PSI:
        PSI(G, T1, B) = 3/7 = 0.429
        PSI(G, T2, B) = 4/7 = 0.571
💡 단순 PSI 평균이 아닌 count 합산 후 재계산을 사용하는 이유:
  • count가 높은 spot의 PSI가 더 신뢰성이 높음
  • count=1인 spot의 PSI(0 또는 1)가 결과를 왜곡하는 것을 방지
  • 통계적으로 올바른 weighted aggregation

필터도 다시 적용: 16µm bin에서도 유전자당 2개 이상 transcript가 검출된 경우만 유지

Part B: AnnData 통합

  1. AnnData 로드: cortex 16µm subset (17,880 spots)
  2. 바코드 매칭: PSI의 16µm 바코드와 AnnData의 바코드를 비교하여 overlap 확인
  3. 대표 transcript 선별: 유전자별 가장 많은 barcode에서 검출된 상위 2개 transcript 선택
  4. PSI wide matrix 구축: (barcode × feature) 형태로 변환
  5. AnnData에 저장:
    • obsm["X_psi"]: 전체 PSI matrix (17,880 × 8,218)
    • obs["psi_{GeneName}"]: 상위 20개 유전자의 major isoform PSI
