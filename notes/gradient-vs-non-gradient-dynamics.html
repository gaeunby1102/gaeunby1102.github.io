Gradient vs Non-gradient Dynamics

2026.07.20

1. Potential function \(V(x)\)란

스칼라 함수. 공간의 각 점 \(x \in \mathbb{R}^d\)에 숫자 하나를 매기는 mapping.

\[ V : \mathbb{R}^d \to \mathbb{R} \]

직관: 지형도의 고도. 산골짜기 그림에서 위치 \((x, y)\)에 높이 \(V(x, y)\)가 적힘.

전형적인 예:

  • Quadratic well: \(V(x) = \tfrac{1}{2}\|x\|^2\) — 원점이 최저점인 단일 그릇
  • Double well: \(V(x) = (x^2 - 1)^2\) — 두 개의 안정 상태 (bistable switch, e.g. EMT의 epi/mes)
  • Multi-stable landscape: 여러 attractor (Waddington 분화 landscape의 직관적 비유)

2. Gradient dynamics 정의

drift가 어떤 \(V\)의 음의 gradient로 표현되는 SDE:

\[ dX_t = -\nabla V(X_t)\, dt + \sigma\, dB_t \]

직관: 공이 지형 위에서 항상 더 낮은 쪽으로 굴러간다. \(-\nabla V\)는 "가장 가파른 내리막 방향"이고, \(\sigma\, dB_t\)는 thermal noise.

핵심: drift vector field \(f(x) = -\nabla V(x)\)가 어떤 scalar 함수의 gradient로 쓸 수 있다는 사실이 본질. 한번 그렇게 쓸 수 있으면 아래 5개 성질이 자동으로 따라옴.

3. Gradient dynamics에서 자동으로 따라오는 5가지 성질

성질수식의미
Curl-free\(\nabla \times f = 0\)회전 성분 없음. polarized "한쪽 방향"만 가능
Conservative\(\oint_C f \cdot d\ell = 0\)폐곡선 적분 0 — 경로 무관, 시작-끝만 의미
Detailed balance\(p(x \to y)\, p_{\infty}(x) = p(y \to x)\, p_{\infty}(y)\)시간 뒤집어도 통계적으로 동일
평형 분포 존재\(p_{\infty}(x) \propto e^{-V(x)/D}\)Boltzmann 분포 (Gibbs measure)
No probability current\(J = p_{\infty} f - D \nabla p_{\infty} = 0\)평형에서 흐름이 정확히 0 — 정적

핵심 함의: 사이클이 원리적으로 안 생긴다. \(A \to B \to C \to A\)로 도는 안정적 순환 흐름은 어떤 \(V\)로도 못 만듦.

왜? — \(A \to B \to C \to A\)로 한 바퀴 돌면 시작점으로 돌아오니까 \(\Delta V = 0\)이어야 하는데, 사이클이 안정하려면 매 단계마다 \(V\)가 감소해야 하니까 모순.

4. Non-gradient (non-equilibrium) dynamics

drift가 어떤 \(V\)의 gradient로 쓸 수 없는 dynamics.

가장 단순한 반례 — 2D 회전 vector field

\[ f(x, y) = (-y,\; +x) \]

  • 원점 중심으로 시계 반대 방향으로 도는 vector field
  • \(\nabla \times f = \partial_x f_y - \partial_y f_x = 1 - (-1) = 2 \neq 0\) → curl 있음

"\(V\)가 존재할 수 없다"는 증명

만약 \(V\)가 존재한다고 가정하면:

\[ \frac{\partial V}{\partial x} = -f_x = y, \qquad \frac{\partial V}{\partial y} = -f_y = -x \]

Cross-derivative를 따져보면:

\[ \frac{\partial^2 V}{\partial x \partial y} = \frac{\partial}{\partial y}(y) = 1, \qquad \frac{\partial^2 V}{\partial y \partial x} = \frac{\partial}{\partial x}(-x) = -1 \]

매끄러운 함수에서는 Clairaut/Schwarz 정리에 의해 두 cross-derivative가 같아야 하는데 \(1 \neq -1\). 모순 → 그런 \(V\)는 존재하지 않음.

Non-gradient system의 통계적 특징

  • Probability current \(J(x)\)가 정상상태에서도 \(\neq 0\) — 끊임없이 도는 흐름
  • Detailed balance 깨짐 — 시간을 reverse하면 다른 system (forward와 backward가 통계적으로 구별됨)
  • Limit cycle, oscillation, irreversible loop, rotational steady-state current 가능

5. 생물 시스템이 non-gradient인 이유

생물은 ATP를 끊임없이 소비하면서 정상상태를 유지하는 non-equilibrium steady state (NESS). 평형 system이면 죽은 거.

시스템회전성 / 비가역성의 모습
Cell cycleG1 → S → G2 → M → G1, 완전한 사이클. potential well로 절대 표현 불가 (V로 만들면 G1으로 굴러내려가 멈춰야 함)
Repressilator (Elowitz–Leibler 2000)3개 gene이 순서대로 서로 억제, 발현이 oscillate. 회로의 Jacobian이 명시적으로 asymmetric
Differentiationirreversible commitment. 한번 분화한 세포가 일반적으로 stem state로 안 돌아옴
EMTepithelial → mesenchymal, partial cyclic / hysteretic — bistable + drug withdrawal로 reverse 안 됨
Metabolic cyclesTCA cycle, glycolytic oscillation — 방향성 있는 순환
Sensory adaptation자극 → 반응 → adaptation → reset, 비가역 loop

이걸 Brownian reference로 잡으려고 하면: 회전 흐름이 noise로 흐려져서 평균 0의 기울기로 보임 → 모델이 정적인 attractor만 학습. v2.x에서 일관되게 관찰된 "shift_corr는 강한데 shift_R²는 약함"의 한 가지 가능한 메커니즘.

6. mvOU의 \(A\) matrix가 이걸 어떻게 해결?

mvOU drift \(A(x - m)\)을 두 부분으로 분해:

\[ A = \underbrace{\tfrac{1}{2}(A + A^\top)}_{A_{\text{sym}}} + \underbrace{\tfrac{1}{2}(A - A^\top)}_{A_{\text{anti}}} \]

\(A_{\text{sym}}\) — gradient 부분

\(A_{\text{sym}}\)은 symmetric이므로 어떤 quadratic potential의 Hessian으로 쓸 수 있음:

\[ A_{\text{sym}}(x - m) = -\nabla V(x), \qquad V(x) = -\tfrac{1}{2}(x - m)^\top A_{\text{sym}}(x - m) \]

  • 고유값이 음수면 \(m\)이 안정 attractor (수렴, well behavior)
  • 고유값이 양수면 \(m\)이 불안정 (repeller)
  • 사이클 못 만듦 — 위 §3의 모든 성질이 이 항에서만 따라옴

\(A_{\text{anti}}\) — non-gradient 부분

\(A_{\text{anti}}\)는 anti-symmetric (\(A_{\text{anti}}^\top = -A_{\text{anti}}\)). 2D에서는 \(\begin{pmatrix} 0 & -\omega \\ \omega & 0 \end{pmatrix}\) 형태로 순수 회전.

  • 고유값이 purely imaginary → trajectory가 spiral / 회전
  • 사이클·oscillation·probability current 표현 가능
  • \(A_{\text{anti}}(x - m) = \omega \cdot R_{90}(x - m)\) 꼴 — 위치 벡터를 90도 돌린 방향으로 push

합쳐서

\(A\)가 일반적으로 symmetric + anti-symmetric 둘 다 가지면, dynamics는 "well로 수렴하면서 동시에 회전"하는 damped spiral / driven oscillator 형태. 정확히 cell cycle, repressilator, EMT 같은 생물 시스템의 모습.

7. 진단 지표 — anti_ratio

논문(Zhang & Stumpf 2026)의 핵심 진단 지표:

\[ \text{anti\_ratio} = \frac{\|A_{\text{anti}}\|_F}{\|A\|_F} \in [0, 1] \]

값해석
\(\approx 0\)거의 symmetric → gradient dynamics에 가까움 → Brownian reference로 충분
중간 (0.3 ~ 0.5)비가역성 + 수렴 혼합. 생물에서 일반적
\(\to 1/\sqrt{2}\)완전 anti-symmetric. 순수 회전 (limit cycle)

⇒ anti_ratio가 크면 그 system은 Brownian reference가 부적합한 증거가 됨. mvOU reference로 바꿔야 할 신호.
