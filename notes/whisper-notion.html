Whisper → Notion 미팅노트 기록 시스템

2026.08.02

개요

1. 음성 → 텍스트 변환 (Whisper)
2. 슬라이드/변환된 스크립트 참고하여 요약 (Claude Sonnet)
3. 노션 데이터베이스에 기록
4. 드롭박스 MD 파일 저장 (원문)
5. 이메일 발송

required

  • 패키지 
    brew install ffmpeg
brew install poppler
pip3 install openai-whisper
pip3 install notion-client
pip3 install anthropic
pip3 install python-pptx
pip3 install dropbox
  • 스크립트
  • API 키 발급
    • Notion API
      • Integration 생성 후 ntn_*으로 시작하는 토큰 복사하고 (https://www.notion.so/my-integrations)
      • 기록할 노션 페이지/데이터베이스에서 Connections → Integration 추가
    • Claude API
      • sk로 시작하는 API key 복사 (https://console.anthropic.com)
    • Dropbox API
      • Create app → Scoped access → Full Dropbox
      • Permissions 탭에서 아래 권한 주기 (꼭 submit 누른 후 토큰 생성해야함)
        • files.content.write/read
        • sharing.write/read
      • Settings 탭에서 토큰 발급
      • 위의 토큰 발급은 short term으로 4시간 후 갱신이 필요함
      • 아래 스크립트 사용
  • Gmail
    • https://myaccount.google.com/security 에서 2단계 인증 (OTP) 활성화 후
    • 앱 비밀번호 검색 → 16자리 비밀번호 (영어) 복사
  • Database ID
    • 현재는 데이터베이스에 매주 페이지 생성을 위해 데이터베이스 ID를 받음
      • 노션 데이터베이스 URL에서 추출하도록 스크립트 작성됨.
      • 매주차 발표자/일자 찾아서 해당 페이지에 추가
  • config.json 만들기 
    {
    "notion_api_key": "ntn_...",
    "claude_api_key": "sk-ant-...",
    "dropbox_token": "sl....",
    "database_id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "gmail_address": "your@gmail.com",
    "gmail_app_password": "xxxx xxxx xxxx xxxx",
    "email_to": [""],
    "email_cc": [],
}

whisper 모델

  • tiny, base, small, medium, large가 있어서 파라미터로 넣어줄 수 있음.

How to run

python3 ~/whisper_to_notion.py "영상파일.mp4" [모델명]
  • 따라서 드롭박스에 슬라이드/녹화본 파일 올릴 때, 형식을 맞추어야함. (날짜/이름 명시)
  • 생성 후 개인 워크스페이스 → 랩미팅 페이지로 옮기기

Cache 관리

  • 변환 결과는 ~/.whisper_cache 에 저장되는데, 같은 파일+ 같은 모델 (medium 등) 조합이 재변환 안되도록 되어 있음.
  • 스크립트 수정 등을 한 경우, rm 으로 캐시 초기화후 실행 필요함.
