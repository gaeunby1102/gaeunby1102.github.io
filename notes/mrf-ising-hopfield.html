MRF / Ising / Hopfield 모델 기반 유전자 조절 네트워크

2026.08.02

논문: Jiang et al. 2026, Cell 189, 4159–4184 | D-SPIN: constructs regulatory network models from scRNA-seq that reveal organizational principles of cellular perturbation responses

핵심 아이디어

D-SPIN은 수천 개의 perturbation 조건에서 측정된 scRNA-seq 데이터를 하나의 통합된 유전자 규제 네트워크로 변환하는 프레임워크다. 이 네트워크를 표현하는 수학적 틀이 바로 Markov Random Field (MRF) — 구체적으로는 물리학의 Ising 모델 및 신경과학의 Hopfield 네트워크와 동일한 구조다.

왜 이 모델인가?

일반적인 GRN 추론 도구들(GENIE3, GRNBoost2 등)은 유전자 발현의 통계적 상관관계에서 규제 관계를 유추한다. 하지만 숨겨진 confounding 인자 때문에 실제 regulatory interaction이 보이지 않는 경우가 많다:

  • 유전자 A와 B가 모두 유전자 C에 의해 억제되면, A-B 사이에는 강한 상관관계가 없는 것처럼 보인다
  • 그러나 C를 knock-down하면 A와 B가 동시에 활성화되어 latent coupling이 드러난다

MRF는 이러한 조건부 독립 구조를 명시적으로 포착하기 때문에, 수천 개의 perturbation 조건을 활용해 이 hidden coupling을 복원할 수 있다.

1. Markov Random Field (MRF) 개요

정의

Markov Random Field는 변수들 사이의 조건부 독립성을 그래프로 표현하는 확률 모델이다.

  • 노드: 각 유전자 (또는 gene program)
  • 엣지: 두 유전자 사이의 직접적인 statistical dependency
  • 핵심 성질: 한 노드는 그 이웃 노드들이 주어졌을 때 나머지 모든 노드와 독립 (Markov property)

Gibbs 분포

MRF에서 전체 시스템의 확률 분포는 Gibbs/Boltzmann 분포로 표현된다:

\(P(\mathbf{s}) = \frac{1}{Z} \exp\left(-E(\mathbf{s})\right)\)

  • \(E(\mathbf{s})\): 에너지 함수 (Energy function)
  • \(Z = \sum_{\mathbf{s}} \exp(-E(\mathbf{s}))\): 정규화 상수 (Partition function)

높은 확률 상태 = 낮은 에너지 상태.

2. Ising 모델과의 연결

Ising 모델이란?

원래 통계물리학에서 강자성(ferromagnetism)을 설명하기 위해 제안된 모델이다. 각 스핀(spin)이 +1 또는 -1 값을 갖는 격자 시스템을 묘사한다.

에너지 함수:

\(E(\mathbf{s}) = -\sum_{i < j} J_{ij} s_i s_j - \sum_i h_i s_i\)

항목의미
\(s_i \in \{-1, +1\}\)각 스핀의 상태
\(J_{ij}\)스핀 \(i\)와 \(j\) 사이의 coupling 강도
\(h_i\)외부 자기장 (external field)
\(J_{ij} > 0\)ferromagnetic (같은 방향 정렬 선호)
\(J_{ij} < 0\)antiferromagnetic (반대 방향 선호)

D-SPIN에서의 대응

D-SPIN은 Ising 모델을 세포 전사 상태에 직접 적용한다:

Ising 모델D-SPIN
스핀 \(s_i\)유전자/프로그램의 활성 상태 (high/low)
Coupling \(J_{ij}\)유전자 쌍 사이의 regulatory interaction
외부 자기장 \(h_i\)Perturbation이 유전자 \(i\)에 가하는 효과
낮은 에너지 상태실제로 자주 관찰되는 세포 상태
에너지 경관 (energy landscape)세포가 취할 수 있는 상태 공간의 확률 분포

3. Hopfield 네트워크와의 연결

Hopfield 네트워크란?

1982년 John Hopfield가 제안한 연상 기억 신경망(associative memory network)이다. Ising 모델과 수학적으로 동일한 구조를 갖는다.

에너지 함수:

\(E(\mathbf{s}) = -\frac{1}{2} \sum_{i \neq j} W_{ij} s_i s_j\)

  • 기억(memory pattern)을 에너지 최솟값으로 저장
  • 잡음이 있는 입력이 주어지면 가장 가까운 기억 패턴으로 수렴

D-SPIN에서의 연결

D-SPIN의 J 행렬은 Hopfield 네트워크의 가중치 행렬 \(W\)에 해당한다:

  • 각 세포 상태 패턴 = Hopfield 네트워크의 메모리 패턴
  • J 행렬 = 모든 perturbation 조건에 걸쳐 학습된 coupling 구조
  • 세포 상태 수렴 = 에너지 최솟값으로의 relaxation

따라서 D-SPIN의 J 행렬을 학습한다는 것은, 어떤 세포 상태들이 안정적으로 존재하는지를 에너지 경관으로 인코딩하는 것과 동일하다.

4. D-SPIN의 수식 구조

핵심 확률 모델

D-SPIN은 perturbation 조건 \(n\) 하에서의 세포 상태 \(\mathbf{s}\) 확률을 다음과 같이 정의한다:

\(P^{(n)}(\mathbf{s}) = \frac{1}{Z^{(n)}} \exp\left(\sum_{i < j} J_{ij} s_i s_j + \sum_i h_i^{(n)} s_i\right)\)

두 개의 핵심 파라미터

① J 행렬 (Coupling matrix) — 공유된 규제 네트워크

\(J \in \mathbb{R}^{p \times p}\)

  • 모든 perturbation 조건에 걸쳐 동일하게 유지되는 행렬
  • \(J_{ij} > 0\): 유전자 \(i\)가 \(j\)를 활성화 (co-activation)
  • \(J_{ij} < 0\): 유전자 \(i\)가 \(j\)를 억제 (mutual repression)
  • 이것이 세포의 내재적 규제 구조 (intrinsic regulatory architecture)

② \(h^{(n)}\) 벡터 (Perturbation response vector) — 조건별 외부 자극

\(\mathbf{h}^{(n)} \in \mathbb{R}^p\)

  • 각 perturbation 조건 \(n\) 에 고유한 벡터
  • \(h_i^{(n)} > 0\): 조건 \(n\)에서 유전자 \(i\)가 상향조절됨
  • \(h_i^{(n)} < 0\): 조건 \(n\)에서 유전자 \(i\)가 하향조절됨
  • Perturbation의 다운스트림 전사 효과를 인코딩

핵심 통찰: 분리 원칙

\(\underbrace{J}_{\text{불변: 세포 내재 네트워크}} \quad \underbrace{\mathbf{h}^{(n)}}_{\text{가변: 각 perturbation의 효과}}\)

J는 세포 종류에 의해 고정되고, h는 perturbation마다 달라진다. 이 분리 덕분에 수천 개의 perturbation 조건에서 하나의 일관된 네트워크 J를 공동 추론할 수 있다.

5. 학습 알고리즘: Pseudolikelihood

왜 Pseudolikelihood인가?

MRF의 완전한 likelihood를 최대화하려면 partition function \(Z\)를 계산해야 하는데, 이는 유전자 수 \(p\)에 대해 지수적으로 복잡 (\(2^p\)가지 상태 열거 필요)하다. 수백~수천 개의 유전자를 다루는 scRNA-seq 데이터에서는 불가능하다.

Pseudolikelihood 근사

Pseudolikelihood는 joint distribution을 조건부 분포의 곱으로 근사한다:

\(\text{PL}(\mathbf{s}) = \prod_i P(s_i \mid \mathbf{s}_{-i})\)

각 유전자 \(i\)의 조건부 분포는:

\(P(s_i \mid \mathbf{s}_{-i}) = \sigma\left(2 s_i \left(\sum_j J_{ij} s_j + h_i^{(n)}\right)\right)\)

  • \(\sigma\): sigmoid 함수
  • \(\mathbf{s}_{-i}\): \(i\)를 제외한 나머지 유전자들의 상태
  • 각 유전자에 대해 독립적인 logistic regression으로 계산 가능

계산 복잡도 비교

방법복잡도
Exact likelihood\(O(2^p)\) — 불가능
Pseudolikelihood\(O(p^2 \cdot N)\) — 실용적

\(p\): 유전자 수, \(N\): 세포 수

방향성 추론 (Directed network)

Pseudolikelihood의 흥미로운 성질: \(i → j\) 방향으로 예측하는 경우와 \(j → i\) 방향으로 예측하는 경우의 예측력 차이(asymmetry)에서 엣지의 방향성을 추론할 수 있다. D-SPIN은 이 asymmetry를 이용해 방향성 있는 GRN을 도출한다.

6. Gene Program으로의 차원 축소

문제: 고차원 유전자 공간

수천~수만 개 유전자 전체에 대해 J 행렬을 추론하면:

  • 계산이 느려지고
  • 유전자별 노이즈에 민감하며
  • 해석이 어렵다

해결: oNMF (Orthogonal Non-negative Matrix Factorization)

D-SPIN은 먼저 유전자 발현을 ~30개의 gene program으로 압축한다:

\(X \approx W H, \quad W \geq 0, \; H \geq 0, \; W^T W \approx I\)

  • \(W\): 유전자 × 프로그램 행렬 (각 program의 유전자 구성)
  • \(H\): 프로그램 × 세포 행렬 (각 세포의 program 활성도)
  • Orthogonality 제약: 각 program이 최대한 독립적 의미를 갖도록

이후 J 행렬은 gene program 수준에서 추론된다:

\(J \in \mathbb{R}^{30 \times 30} \quad \text{(유전자 수천 개 대신 30개 노드)}\)

모듈 coarse-graining

30개 program을 추가로 graph clustering하여 4~7개의 functional module로 묶는다:

K562 모듈 예시기능
전사 (Transcription)RNA pol II 관련
번역 (Translation)리보솜 단백질
단백질 분해 (Degradation)프로테아솜
대사 (Metabolism)에너지/물질 대사
DNA 복제 (Replication)세포 주기

7. Drug Combination 예측: Additive Sigmoid 모델

조합 반응 모델링

단일 약물 두 개의 perturbation response vector h가 주어졌을 때, 조합의 효과를 다음과 같이 모델링:

\(h_{\text{combo}}(c_1, c_2) = \sigma_1(c_1) + \sigma_2(c_2) + \gamma \cdot \sigma_1(c_1) \cdot \sigma_2(c_2)\)

  • \(c_1\), \(c_2\): 각 약물의 농도
  • \(\sigma_k(c) = \frac{A_k}{1 + \exp(-\alpha_k(\log c - \beta_k))}\): sigmoid dose-response curve
  • \(\gamma\): interaction coefficient (synergy/antagonism 측정)

학습 데이터 요구량

파라미터필요 데이터
\(\sigma_1\)의 파라미터약물 1 단독 titration
\(\sigma_2\)의 파라미터약물 2 단독 titration
\(\gamma\) (interaction)조합 실험 단 1개

→ 전체 2D dosage phase diagram을 단 한 번의 조합 실험으로 interpolation 가능

  • 강하게 co-regulated된 유전자 쌍이 baseline에서는 uncorrelated하게 보이는 현상을 D-SPIN이 정확히 복원
  • 단일 perturbation이나 무작위 발현 상관관계만으로는 절대 발견되지 않는 coupling이 수천 개 perturbation의 공동 분석에서 드러남

9. 생물학적 해석

세포 항상성 반응 전략 (Homeostatic response)

K562 세포에서 ~10,000 KD를 분석한 결과, 세포는 다양한 genetic perturbation에 대해 4가지 반복 전략으로 반응:

  1. 대사 상향 (Metabolism-up)
  2. 전사 상향 (Transcription-up)
  3. 번역 상향 (Translation-up)
  4. 단백질 분해 상향 (Degradation-up)

→ 이 전략들은 네트워크 모듈 사이의 homeostatic coupling에서 비롯됨

예시: GATA1 KD → 단핵구 증가

D-SPIN J 행렬 분석:

  • GATA1 KD → PU.1 탈억제 → EgrNab 경로 활성화 → 단핵구 분화 프로그램 활성

이 인과관계는 J 행렬의 엣지 구조에서 직접 읽어낼 수 있음 (post-hoc 추론 불필요)
